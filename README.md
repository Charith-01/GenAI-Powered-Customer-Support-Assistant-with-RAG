# GenAI Customer Support Assistant with RAG

## Project Overview

This project develops a Generative AI-based customer support assistant capable of analyzing customer support tickets and generating appropriate responses.

The project will progressively include:

- Customer ticket analysis
- Ticket classification
- Priority detection
- AI-generated support responses
- Retrieval-Augmented Generation (RAG)
- Policy-based response generation
- Model evaluation
- Streamlit web application

## Project Status

🚧 Currently under development.

## Project Structure

- `data/` - Customer support datasets
- `knowledge_base/` - Documents used for RAG
- `notebooks/` - Data analysis and experiments
- `src/` - Application source code
- `evaluation/` - Evaluation datasets and results
- `screenshots/` - Application screenshots
- `report/` - Final project documentation

## Technologies

- Python
- Pandas
- Generative AI / LLM
- RAG
